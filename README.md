# maiCare Foundation website

Website for maiCare Foundation Inc., San Carlos City, Pangasinan. Information only: no online payments.

- Plan: `WEBSITE-PLAN.md`
- Build status: `PROGRESS.md`
- Project rules (for AI sessions): `CLAUDE.md`

## Run it on your computer

Needs Node.js 22.23.4 or newer.

```
npm install      # first time only
npm run dev      # opens a local site at http://localhost:4321
npm run build    # makes the final site in dist/
```

Contact details, the emergency banner switch and the goals numbers are all in `src/data/site.ts`.
